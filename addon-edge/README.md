# Domus Edge

Development preview of Domus installed as a Home Assistant app. Open it through HA's Open Web UI;
it uses your existing HA sign-in without another login.

Edge 0.0.0-edge.5 packages the English/Spanish household entry interface: verified access, explicit
household setup, own pending membership and original-request recovery. Technical status follows the
selected language. It uses private SQLite schema 7 while retaining identity, household records and
operation history; existing Edge.4 data remains compatible. The remaining domain
screens and complete product acceptance remain under development. Set your Home Assistant browser
origins in the app's Configuration tab before starting. It remains experimental, with no stable release.

See [installation and permissions](DOCS.md).
