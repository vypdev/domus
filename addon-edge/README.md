# Domus Edge

Development preview of Domus installed as a Home Assistant app. Open it through HA's Open Web UI;
it uses your existing HA sign-in without another login.

Edge 0.0.0-edge.3 adds retained operation history and console-only restoration with interrupted
activation recovery. Private persistent identity, household APIs, bounded sessions and administrator
recovery remain included. The complete product UI remains under development. Set your Home Assistant browser
origins in the app's Configuration tab before starting. It remains experimental, with no stable release.

See [installation and permissions](DOCS.md).
